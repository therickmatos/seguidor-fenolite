=== MAPA DE PINOS DO ESP32-C3 SuperMini ===
  IO5  -> BI_B     | BI motor DIR (strapping leve, so saida)
  IO6  -> FI_B     | FI motor DIR  -> 10k pull-down (MTCK tem pull-up no reset)
  IO7  -> BI_A     | BI motor ESQ (glitch 5ns inofensivo)
  IO8  -> S0       | S0 do mux (strapping; nada forca nivel no boot)
  IO9  -> S1       | S1 do mux (BOOT; pull-up do modulo mantem)
  IO10 -> FI_A     | FI motor ESQ (seguro no boot)
  IO20 -> S2       | S2 do mux (RX, pull-up no boot)
  IO21 -> S3       | S3 do mux (TX, log no boot)
  IO0  -> MK_L     | Sensor marca ESQ (ADC1)
  IO1  -> MK_R     | Sensor marca DIR (ADC1)
  IO2  -> BTN      | Botao (strapping; precisa 10k pull-up p/ 3V3 -> SPI boot)
  IO3  -> GATE_D   | GATE turbina via 220R (+10k p/ GND)
  IO4  -> C0       | C0 do mux (ADC1)
  3V3  -> 3V3      | saida do AMS1117
  GND  -> GND      | plano de terra
  5V   -> NC_5V    | NAO conectado (sem 5V na placa)
