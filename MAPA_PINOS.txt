=== MAPA DE PINOS DO ESP32-C3 SuperMini ===
  5V   -> NC_5V    | NAO conectado
  GND  -> GND      | plano de terra
  3V3  -> 3V3      | saida do AMS1117 / pino 1 da barra
  IO4  -> C0       | C0 do mux (ADC1) - reto ate a barra
  IO3  -> S3       | S3 do mux - reto ate a barra
  IO2  -> S2       | S2 do mux - reto ate a barra (GPIO2 nao define o boot, so glitch)
  IO1  -> S1       | S1 do mux - reto ate a barra
  IO0  -> S0       | S0 do mux - reto ate a barra
  IO5  -> FI_A     | FI motor ESQ
  IO6  -> GATE_D   | GATE turbina via 220R; 4k7 p/ GND (pull-up de reset -> 0,31 V)
  IO7  -> BI_A     | BI motor ESQ
  IO8  -> MK_L     | sensor de marca ESQ (digital, pull-up 47k)
  IO9  -> BTN      | botao (= BOOT do modulo, pull-up interno)
  IO10 -> BI_B     | BI motor DIR
  IO20 -> FI_B     | FI motor DIR; 10k p/ GND (pull-up no reset)
  IO21 -> MK_R     | sensor de marca DIR (digital, entrada)
